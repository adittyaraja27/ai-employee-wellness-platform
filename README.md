-> AI-Based Employee Wellness Management Platform

An AI-powered employee wellness platform developed as part of the **Infosys Springboard Virtual Internship**
Mood Mentor is designed to analyze employee-written text, identify sentiment and emotional indicators, and eventually provide personalized wellness recommendations. The current implementation focuses on the foundational NLP pipeline for text ingestion, preprocessing, and baseline sentiment analysis.

-> Project Overview

Employee wellness can be affected by factors such as workload, stress, workplace relationships, and job satisfaction. Employees may express these experiences through written feedback or text responses.
This aims to process this text and provide meaningful insights using Natural Language Processing (NLP).
The current pipeline is:

Employee
     ->
Text Ingestion
     ->
Input Validation
     ->
Text Preprocessing
     ->
VADER Sentiment Analysis
     ->
Sentiment Classification
     ->
Sentiment Report
